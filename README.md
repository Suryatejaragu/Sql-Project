# SQL Project – PostgreSQL (pgAdmin)

This project demonstrates various SQL queries and database operations implemented using **PostgreSQL** in **pgAdmin**.  
The project focuses on working with **multiple tables**, using **JOINs**, **aggregation**,**DateFunctions** and other SQL concepts to extract meaningful insights from the data.

---
## 📂 Project Overview

The project includes:
- Database creation and table setup
- Data insertion
- Data retrieval using:
  - `INNER JOIN`
  - `LEFT JOIN`
  - `RIGHT JOIN`
  - `FULL JOIN`
- Filtering with `WHERE` and `HAVING`
- Aggregations using `GROUP BY` and aggregate functions
- Ordering results with `ORDER BY`
- Subqueries and Nested Queries

---

## 🛠 Tools & Technologies

- **Database:** PostgreSQL
- **IDE / GUI:** pgAdmin 4
- **SQL Concepts Used:** Joins, Aggregation, Filtering, Subqueries
